【Wi-Fi MEDIA かんたん起動版 v4】

今回の版は、Flaskなどの追加ソフトを使わず、Macに入っているPythonだけで動くようにしました。
また、5000番ポートが他のソフトで使われていても、5050〜5090から空いている番号を自動で選びます。

■ いちばん簡単な使い方
1. このZIPをダウンロード
2. ZIPをダブルクリックして解凍
3. フォルダを開く
4. 「start.command」をダブルクリック
5. Chromeが自動で開いたら成功です

■ 管理画面
Chromeで自動的に開きます。
例：
http://127.0.0.1:5050/admin

■ 公開ページ
例：
http://127.0.0.1:5050/

■ 大事
admin.html と web.html を直接ダブルクリックしないでください。
必ず start.command をダブルクリックしてください。

■ スマホで見る
Macとスマホを同じWi-Fiにつなぎます。
start.commandを起動したあと、黒い画面に表示された「管理画面」「公開ページ」の番号を確認します。
MacのIPアドレスが192.168.1.20だった場合、
スマホで
http://192.168.1.20:5050/
のように開きます。
※番号は5050とは限りません。黒い画面に出た番号を使ってください。

■ 今できること

これは「仕組みを試すプロトタイプ」です。
本番サービスにする場合は、インターネット公開、ログイン、データベース、画像保存、Wi-Fi接続数の自動取得などを追加します。
